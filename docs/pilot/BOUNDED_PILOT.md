# One-collection pilot worksheet

Status: proposed; not conducted or authorized externally.

Participants: one campus mess, one NGO and one volunteer. Scope: one explicitly
confirmed donation in one zone, with the ordinary claim and pickup-agreement flow.

Before launch record organisational approval, volunteer availability, capacity,
ingredient/handling declarations, packaging and agreed pickup/delivery deadline.
Confirm the real phone receives a provider alert before relying on it. Keep the
participants' agreed fallback contact procedure available if the app is offline.

| Observation | Planned | Actual / source |
| --- | --- | --- |
| Consent and collection approval | Required | Not collected |
| Donor listing and quantity | One whole listing | Not measured |
| Alert acceptance / phone receipt | Record both separately | Not observed |
| Listing-to-claim time | UTC timestamps | Not measured |
| Collection agreement / pickup | Participant confirmation | Not observed |
| Delivered mass | Actual measurement with method | Not measured |
| Declined food, changed quantity, missed timing | Record deviations | Not observed |
| Donor / NGO follow-up | Permission-based quote or summary | Not collected |

Store anonymised results in a dated report; keep raw identities private. Explain
measurement uncertainty and compare the observed collection with the participants'
existing process. Do not extrapolate one collection to annual impact.
